## Features

**Store** - Secure file storage in a centralized location accessible from anywhere via web interface

**Find** - Powerful search capabilities and organized file structure with intuitive navigation

**Collaborate** - Share files and folders with team members with granular access control

**Self-host** - Easy to install, scalable and secure file storage solution
